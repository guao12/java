# 登录页改版方案

> 范围：`DragonRaja-Vue/src/views/LoginView.vue` 及其外壳（`AuthLayout.vue` / `theme.css` 认证卡片段）
> 参考：`longzu/index.html` 的 `#login-page`（第 723–931 行 CSS / 第 1230–1285 行 DOM）
> 日期：2026-11-12　版本：v1

---

## 〇、前提与结论

**前提**：现网登录页 = `DragonRaja-Vue` 的鎏金玻璃卡片；目标参考样式 = `longzu` 原型的冷银蓝单列登录页。以下分析基于这个对应关系，若理解有偏差请先纠正再落地。

**三条结论先行**：

1. **改版的真正动因不是"现有页面不好看"，而是风格断裂。** 落地层（`LandingView` / `PortalView`）已经是冷银蓝调（`--silver-bright: #dce2ee`、`bg: #0e1830→#142040`），而登录页仍是暖金（`--gold: #d8b25a`）。用户从门户点「进入学院」会经历一次明显的色调跳变。
2. **参考稿只能借"形"，不能借"交互"。** 原型是静态的：登录按钮没绑事件、没有校验、没有错误态、没有加载态。照搬会把现有 7 项可用性能力全部做倒退。
3. **最大的技术风险不是样式，是外壳共用。** `/login`、`/register`、`/forgot`、`/console`、`/admin/login` 五个页面共用 `AuthCard`，四个页面共用 `AuthLayout`。只改登录页会造成认证流程内部割裂。

## 一、两个对象的定量对比

| 维度 | 现有登录页 | 目标参考 |
|---|---|---|
| 实现载体 | `LoginView.vue`（975 行）+ `AuthLayout` + `AuthCard` + `IdCardPreview` | 单文件内联，`#login-page` 约 55 行 DOM / 208 行 CSS |
| 卡片宽度 | 452px（`is-wide` 时 486px） | 420px |
| 整页高度（桌面估算） | **约 1000–1050px**（34 顶距 + 44 品牌栏 + 26 + 卡片约 820 + 页脚约 72） | **约 620–660px** |
| 纵向模块数 | 18 个堆叠区块 | 5 个 |
| 交互模块数 | 21 个 | 12 个元素（其中 4 个是真输入） |
| 主色 | 鎏金 `#d8b25a` | 银蓝 `#dce2ee` / `#b8c2d4` |
| 背景 | Canvas 法阵 + 粒子（`RuneBackground`，800 行） | 一张照片，`brightness(.35) contrast(1.1) saturate(.8)` |
| 卡片材质 | 金边 + 四角封印 + 顶部金线 + 内部暖光 | 单层银蓝描边 + `blur(20px)` + `radius 20px` |
| 最高标题字号 | 约 30px（`auth-title`） | `clamp(26px, 6.5vw, 36px)`，字距 10px |

### 1.1 布局差异

**现有：三级外壳 + 卡片内容承载一切**

```
.app-shell (padding 34 22 40)
├─ .brand-bar          左：徽记34px + 「卡塞尔学院 / Cassell College·Secret Archive」
│                      右：「● 龙文密钥通道·已加密」        ← 与卡片副标题语义重复
├─ .stage (padding 26 0 16, flex center)
│  └─ .login-stage (452px) → AuthCard
│     ├─ badge「Cassell College · Access」
│     ├─ H1「身份认证」+ 副题
│     ├─ tabs「登录 | 注册」
│     ├─ IdCardPreview（约 150px，独立一张"卡中卡"）
│     ├─ 学号字段 → 历史 chips → 上次登录行
│     ├─ 密钥字段 → 大写锁定 → 强度条 → 记住我/忘记
│     ├─ 欢迎语 → alert → 主按钮 → 快捷键提示
│     ├─ 「或」→ 演示身份卡按钮
│     ├─ 后端通道状态 + 信号格
│     └─ foot「还没有身份卡？前往新生登记」
└─ .page-foot          版权 + 登录/注册/找回 三个重复链接
```

问题：**品牌信息出现三次**（品牌栏、卡片 badge、页脚），**注册入口出现四次**（tabs、foot、页脚 nav、以及原型里的新生按钮缺失）。纵向堆叠到 ~820px 的卡片已经让页面在 1440×900 / 1366×768 下必须滚动——登录页滚动是不该发生的。

**目标：单列引导式，卡片只装表单**

```
#login-page
├─ .login-bg          照片 + 三层纵向暗化遮罩（顶部 .6 → 中部 .4 → 底部 .8）
└─ .login-wrap (flex column, align center, max-width 420)
   ├─ .login-top      ← BACK
   ├─ .login-intro    徽记 72px → CASSELL COLLEGE(13px/字距5) → 「登 录 学 院」(字距10) → 副题
   └─ .login-card     学号 → 密码(带"显示") → 记住我/忘记 → 主按钮 → 「新生入口」分隔 → 新生按钮
```

关键结构差异：**徽记与标题从"卡片内"移到"卡片外上方"**。这一步把卡片高度从 ~820px 压到 ~380px，是整页不滚动的决定性改动。

### 1.2 视觉风格差异

| 项 | 现有（暖金 · 玻璃拟态） | 目标（冷银蓝 · 电影感） |
|---|---|---|
| 页面底色 | `#05070d → #080c16` | `#0c1428 → #101c34 → #080c16` |
| 强调色 | `#d8b25a`（金）贯穿边框、按钮、图标、焦点环 | 金色**退为 hover 点缀**，结构色用 `rgba(150,180,225,.22)` |
| 卡片背景 | `linear-gradient(165deg, rgba(20,28,46,.86), rgba(8,12,22,.92))` | `rgba(10,16,30,.65)` + `blur(20px)` |
| 卡片边框 | `1px var(--line)` = 金 18% | `1px rgba(150,180,225,.22)` |
| 圆角 | 18px | 20px |
| 装饰 | 四角封印 ×4 + 顶部金线 + 径向暖光 + 噪点 | 无（纯单层描边） |
| 主按钮 | 金渐变 + 金色投影 | 描边玻璃：`rgba(18,28,50,.5)` + 银蓝边，hover 才转金边 |
| 标题色 | `#ece7dc` + 金晕 | `#dce2ee` + `0 0 30px rgba(155,185,235,.15)` |
| 字体 | Cinzel / Noto Serif SC（同） | 同，但 H1 字距 10px、副题 13.5px/字距 2px |
| 背景动效 | 800 行 canvas 法阵 + 粒子 | 静态照片（0 JS） |

### 1.3 交互流程差异

**现有（7 段）**
```
进页 ──► 探活后端(GET /api/auth/dictionaries) ──► 输入(身份卡实时刷新+强度条)
   ──► 校验(抖动/alert) ──► 提交(金按钮 loading) ──► 扫描过场+打字机 1.6s ──► push
         ↑失败：抖动 + 剩余次数 + 5 次锁 30s
```
**目标（2 段）**：输入 → 点按钮。原型没有反馈层。

判断：不能砍到 2 段。登录页的失败反馈、大写锁定、锁定冷却都是真实收益；该砍的是**与登录无因果关系的装饰性反馈**（身份卡预览、密钥强度评级、后端信号格）。

### 1.4 功能组成差异

| 能力 | 现有 | 目标 | 差距性质 |
|---|---|---|---|
| 账号 / 密码 / 记住 / 忘记 / 提交 | ✅ | ✅ | 一致 |
| 表单校验与错误提示 | ✅ | ❌ | 现有更强，须保留 |
| 失败锁定（5 次 / 30s） | ✅ | ❌ | 现有更强，须保留 |
| 大写锁定提示 | ✅ | ❌ | 现有更强，须保留 |
| 注册入口 | ✅ ×4 处 | ✅ ×1 处 | 现有冗余，应收口 |
| 返回门户 | ❌ | ✅ `← BACK` | **缺失，须新增** |
| 徽记 + 大标题引导区 | 卡内、较小 | 卡外、独立区块 | 须改造 |
| 身份卡实时预览 | ✅ | ❌ | 与登录无因果，建议移出 |
| 密钥强度评级 | ✅ | ❌ | 位置错，应属注册页 |
| 后端健康探测 | ✅ | ❌ | 开发期信息，生产无意义 |
| 演示身份卡 | ✅ | ❌ | 前端硬编码口令，建议删 |
| 快捷键提交 | ✅ | ❌ | 低成本，可留 |

## 二、改版建议

### 2.1 目标形态（新结构树 + 尺寸）

```
<div class="login">                                    ← 局部作用域覆盖银蓝令牌
  ├─ <div class="login__bg">  照片 srcset 1024/768/512（复用 portal 的 bg-cassell）
  ├─ <div class="login__top"> ← 返回门户          height 30
  ├─ <header class="login__intro">                 margin 12 auto 28
  │   ├─ 徽记 72px（border-radius 50%，border rgba(150,180,225,.15)）
  │   ├─ CASSELL COLLEGE                          13px / 字距 5px / --silver
  │   ├─ 登 录 学 院                              clamp(26,6.5vw,36) / 字距 10px / 900
  │   └─ 凭学号或姓名，回到守夜人的岗位              13.5px / 字距 2px
  └─ <section class="login__card">                w 100%, max 420, radius 20, blur 20
      ├─ 页签「登录 | 注册」                       保留（可用性）
      ├─ 学号字段（含历史账号下拉）                 62
      ├─ 密钥字段（图标式显隐 + 大写锁定）           62
      ├─ 记住我 · 忘记密钥                         24
      ├─ alert / 锁定倒计时                        按需
      ├─ 主按钮「进入学院」                         52
      └─ 「新生入口」分隔 + 次级按钮 → /register     44
</div>
```

目标高度：`30 + 12 + 72 + 16 + 14 + 44 + 10 + 20 + 28 + 卡片约 360` ≈ **640px**。1440×900 与 1366×768 均无需滚动。

### 2.2 模块处置矩阵

| 模块 | 处置 | 具体做法 | 理由 |
|---|---|---|---|
| 品牌栏 `brand-bar` | **本页移除** | `AuthLayout` 加 `bare` prop，登录页不渲染；品牌信息由 intro 承担 | 与 intro 重复，占 44px |
| 法阵粒子 `RuneBackground` | **本页降载** | 照片背景之上让 canvas `opacity:.15`；或直接 `v-if` 关掉 | 800 行 canvas 压照片会糊，且双动效抢注意力 |
| 3D 倾斜 + 光晕跟随 | **保留降幅** | `9°/7° → 4°/3°`；`pointerType==='touch'` 与 `prefers-reduced-motion` 已处理，不动 | 现有手感最好的一处，成本 0 |
| 引子区（徽记+标题+副题） | **改造外置** | 从 `AuthCard` 内搬到卡片上方，尺寸按 2.1 | 压高度的关键一步 |
| 登录/注册页签 | **保留** | 样式改银蓝下划线 | 原型无页签，但页脚文字找注册体验更差 |
| 身份卡预览 `IdCardPreview` | **移出登录页** | 登录页删；`ConsoleView` 已有使用，能力不丢 | 150px 换 0 业务价值 |
| 历史账号 chips | **合并进字段** | 字段右侧 caret 唤起下拉，选中即填入并聚焦密码 | 省 24px，不打断表单节奏 |
| 上次登录 + 清除记录 | **降级为一行** | 12px 细字，右对齐放在「记住我」行内 | 有价值，但别独占两行 |
| 密钥强度条 | **移至注册页** | 注册页有对应语义；登录页删 | 登录时评"强度"没有决策意义 |
| 大写锁定提示 | **保留** | 原样 | 真实降低输错率 |
| 扫描过场 + 打字机 | **保留缩短** | 1600ms → 700ms；打字机 42ms/字 → 22ms | 1.6s 白等太久，体感是"卡" |
| 抖动 shake | **保留** | 520ms → 420ms | 失败反馈必要 |
| 主按钮 | **改造** | 金渐变 → 描边玻璃；hover 才出金边 + 金光 | 对齐参考稿，且金色变"稀缺奖励" |
| 快捷键提示 | **保留降级** | 挪到按钮下 11px 灰字 | 低成本 |
| 「或」+ 演示身份卡 | **退役** | 前端硬编码 `CC20260001 / Dragon@2026`，等同后门；改 DEV-only 或彻底删 | 安全 |
| 后端通道 + 信号格 | **退役 / DEV-only** | 硬编码 `192.168.68.1:8082` 泄露内网拓扑 | 安全 + 无用户价值 |
| `← BACK` 返回门户 | **新增** | 有 `history` 时 `router.back()`，否则 `/portal` | 原型有，现在从门户进登录就回不去了 |
| 页脚三链接 | **精简** | 只留版权；导航合并到页脚右侧一处 | 消除 4 处重复注册入口 |

净变化：**删 5 个模块、移出 2 个、合并 1 个、新增 1 个、改造 4 个、保留 8 个**。

### 2.3 视觉令牌落地方式（关键）

不要动 `theme.css` 的全局 `--gold`——那会波及论坛、档案室、后台。沿用落地层已验证的写法：**在页面根元素上做局部覆盖**。

```css
.login {
  /* 结构色：冷银蓝 */
  --silver-bright: #dce2ee;
  --silver: #b8c2d4;
  --line-frost: rgba(150, 180, 225, 0.22);
  --line-frost-soft: rgba(130, 155, 200, 0.13);

  /* 金色保留为强调色，只在 hover / 成功 / 选中出现 */
  --accent: var(--gold-lt);
}
```

映射表：

| 现有引用 | 改为 |
|---|---|
| `border: 1px solid var(--line)` | `1px solid var(--line-frost)` |
| `--gold` 用于图标/焦点环 | `--silver`，`hover` 时 `--accent` |
| `background: linear-gradient(165deg, rgba(20,28,46,.86), …)` | `rgba(10,16,30,.65)` |
| `.corner--*` 四角 | 删除 |
| `.auth-card::before` 顶部金线 | 删除 |
| `.auth-card::after` 径向暖光 | 换 `radial-gradient(90% 60% at 50% -20%, rgba(120,160,220,.10), transparent 70%)` |

### 2.4 响应式与可达性

- **≥768px**：单列居中，`max-width 420`，背景 `object-position: center top`。
- **<768px**：`login__wrap` 左右 padding `20px`，卡片 `width: 100%`；intro 保持居中（原型小屏改左对齐会让竖屏显得松散，这里不跟随）。
- **<420px**：H1 字距 `10px → 7px`，副题 `13.5 → 13px`。
- **对比度**：原型 `--text-dim: rgba(120,140,170,.45)` 在 `#0c1428` 上实测约 **2.1:1**，远低于 AA——**占位符与「新生入口」分隔标签不能照抄**，改用 `--text-3 #9aa2b6`（theme.css 已按 6.65:1 校准）或 `--text-4 #858da1`。
- `aria-live="polite"` 挂在 alert 区；`focus-visible` 焦点环用 `--silver` 而非移除 outline；`prefers-reduced-motion` 下关扫描线、关倾斜。

## 三、优先级与排期

| 级别 | 内容 | 预估 | 验收标准 |
|---|---|---|---|
| **P0** 结构 | 单列布局、引子区外置、卡片瘦身、页面不滚动 | 1.0 人日 | 1440×900 / 1366×768 无滚动条；主按钮首屏可见 |
| **P1** 视觉 | 银蓝令牌、照片背景、去四角/金线、主按钮描边玻璃 | 0.8 人日 | 与 `PortalView` 并排无色调跳变；首屏图 ≤ 400KB |
| **P2** 交互 | 时长压缩、历史账号下拉、返回门户、DEV-only 清理 | 0.6 人日 | 提交到跳转 ≤ 700ms；`← BACK` 可达门户 |
| **P3** 一致性 | `RegisterView` / `ForgotView` / `ConsoleView` 同步 | 1.0 人日 | 四页视觉同一套令牌；无孤立金边 |
| **P4** 收口 | 文档、演示账号说明、删除项登记 | 0.3 人日 | README 与实际一致 |

**建议先做 P0+P1（约 2 人日）出可评审版本，再决定 P3 是否一次做完。**

## 四、风险与缓解

| # | 风险 | 触发条件 | 缓解 |
|---|---|---|---|
| R1 | **认证流程内部割裂** | 只改登录页，点「注册」跳到仍是鎏金的页面 | P0 阶段就把 `AuthLayout` 加 `bare` prop 而非硬改；P3 必须排期，不能无限期后置 |
| R2 | **背景图与 canvas 打架** | 照片 `brightness(.35)` 之上叠法阵粒子，画面发灰发脏 | 本页 canvas `opacity:.15` 或关停；实测后再定 |
| R3 | **对比度回归** | 直接沿用原型的 `--text-dim` / `--text-secondary` | 只用 theme.css 已校准的 `--text-2/3/4`；占位符不低于 `--text-3` |
| R4 | **本地调试退化** | 删掉后端状态提示后，连不上库时页面无任何线索 | 保留为 `import.meta.env.DEV` 条件块，生产构建自动消失 |
| R5 | **演示入口断裂** | 删掉「使用演示身份卡」后，演示/验收流程要手输 | 同上，DEV-only 保留；README 注明账号来源 |
| R6 | **全局 `overflow:hidden` 事故** | 从原型整段搬 CSS，带上 `html,body{overflow:hidden}` | 只复制卡片段样式；`LoginView` 的 style 保持 `scoped` |
| R7 | **`remember` 语义被误改** | 把「记住我」顺手改成纯 UI 勾选 | 不动 `saveSession({remember})`：true→`localStorage`，false→`sessionStorage` |
| R8 | **无视觉回归网** | 环境无浏览器，改动只能靠肉眼 | P0 后用 SSR 结构断言兜底（已可跑），并建议装 Playwright 做 4 档截图对比 |
| R9 | **路由守卫联动** | 新增 `← BACK` 用了 `history.back()`，从书签直达时会退出站点 | 判断 `window.history.state?.back` 是否为空，空则 `push('/portal')` |

## 五、验证清单

**布局**
- [ ] 1920×1080 / 1440×900 / 1366×768 无纵向滚动，主按钮在首屏
- [ ] 375×812 可滚动，但首屏能看到标题与首个字段
- [ ] 卡片宽度 420，两侧留白对称

**视觉**
- [ ] 与 `/portal` 并排对照无色调跳变（同一 `--silver-*`）
- [ ] 页面内金色只出现在 hover / 成功 / 选中态
- [ ] 首屏图片 ≤ 400KB，LCP 图不做 `lazy`

**交互**
- [ ] 空账号 / 空密码 / 密码 <6 位 → 字段级报错 + 抖动
- [ ] 密码错 → alert + 剩余次数；第 5 次 → 锁定 30s 倒计时
- [ ] 后端 500 → 提示可读，不清空已输入内容
- [ ] 成功 → 扫描过场 → 700ms 内跳转 `?redirect` 或 `/forum`
- [ ] 大写锁定提示出现/消失
- [ ] `← BACK` → 有历史回退，无历史去 `/portal`
- [ ] 历史账号下拉：选中填账号并聚焦密码，删除后不再出现

**可达性**

## 七、附带发现（与改版无关但顺手可清）

1. `LoginView.vue:246-252` `fillDemo()` 前端硬编码账号 `CC20260001` / 口令 `Dragon@2026`。
2. `LoginView.vue:521` 卡片底部硬编码 `192.168.68.1:8082`——写死了一台机器的局域网地址，换机即失效且泄露内网拓扑。
3. `LoginView.vue:434` 历史账号 chip 的删除按钮用 `<span role="button" tabindex="0">` 嵌套在 `<button>` 内——**按钮不能嵌套交互元素**，HTML 校验不通过，且屏幕阅读器会读出两个按钮。改版时换成并列的 `<button>` 或整行删除。
4. 页脚、tabs、card foot、页脚 nav 共 4 处注册入口，收口到 1 处后需同步更新 `README` 的页面结构说明。
